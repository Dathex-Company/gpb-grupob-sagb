# Registry — NIDE

Este diretório será o futuro registro interno de domínios do NIDE.

Cada domínio terá seu próprio manifesto, e o registry será responsável por:
- Gerenciar o ciclo de vida dos domínios
- Controlar lazy loading
- Validar dependências entre domínios

**Status:** Não implementado. Previsto para ET 06/08.
