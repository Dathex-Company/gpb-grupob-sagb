# falas_user

## objetivo
Registro exclusivo das mensagens do usuário para rastreabilidade, continuidade de contexto e retomada multi-dispositivo.

## vinculação canônica
Este arquivo segue a Regra 4 do padrão canônico em `docs/governanca_sagb/padrao_unificado_governanca.md`.

## padrão obrigatório
- registrar apenas falas do usuário (sem respostas do agente);
- manter ordem cronológica;
- formato append-only;
- timestamp no fuso local do usuário.
- registrar a fala literal, sem resumir, sem reescrever e sem normalizar texto.
