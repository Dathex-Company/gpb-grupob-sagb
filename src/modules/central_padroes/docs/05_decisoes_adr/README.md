# ADRs Loze | Central de Decisões Estruturais

## O que é ADR

ADR (Architecture Decision Record) é um registro formal de decisão estrutural com contexto, decisão, impacto e consequências.

## Quando criar ADR

Criar ADR quando a decisão:

- altera direcionamento institucional/técnico;
- afeta múltiplos módulos, equipes ou operações;
- define regra de precedência, governança ou arquitetura;
- precisa rastreabilidade histórica para evitar retrabalho.

## Regra central

**Decisão estrutural vira ADR.**

## Relação com LOZE-GOV

Este diretório operacionaliza `LOZE-GOV` para decisões estruturais. Regras normativas em validação devem ser consolidadas em ADR antes de virar padrão oficial.
