# ADR-005 — GitHub/repositório como fonte técnica oficial

## 1. Título
GitHub/repositório como fonte técnica oficial.

## 2. Status
aprovado com ajustes

## 3. Contexto
Havia dispersão documental e risco de múltiplas “fontes verdade” técnicas.

## 4. Decisão
Definir o repositório técnico versionado (GitHub) como fonte técnica oficial para código, histórico de mudanças e documentação técnica vinculada.

## 5. Motivo
- rastreabilidade;
- versionamento confiável;
- auditoria e colaboração.

## 6. Consequências
- documentos fora do repositório passam a ter papel complementar;
- decisões estruturais devem apontar para artefatos versionados.

## 7. Impacto
alto (governança técnica e compliance interno).
