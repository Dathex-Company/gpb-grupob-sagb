## 6. Método de curadoria profunda

Para cada domínio, seguir este método:

1. Abrir o v3.0 atual.
2. Abrir a fonte v1.0 correspondente.
3. Abrir a fonte v2.0 correspondente.
4. Criar uma leitura comparativa por seção.
5. Identificar no v1/v2 conteúdos que não aparecem no v3.0.
6. Separar o conteúdo por tipo:
   - princípio;
   - política;
   - regra;
   - padrão;
   - protocolo;
   - processo;
   - procedimento;
   - checklist;
   - matriz;
   - registro/evidência;
   - risco;
   - lacuna;
   - decisão;
   - dependência;
   - exemplo;
   - fluxo;
   - subdocumento previsto.
7. Inserir cada conteúdo na seção correta do v3.0.
8. Melhorar tabelas existentes quando necessário.
9. Adicionar novas linhas em tabelas existentes quando necessário.
10. Adicionar novos fluxos Mermaid quando necessário.
11. Adicionar exemplos práticos quando o documento estiver genérico.
12. Atualizar a seção de subdocumentos previstos.
13. Atualizar a seção de monitoramento.
14. Atualizar a seção de lacunas.
15. Atualizar a seção de decisões.
16. Preservar linguagem neutra e institucional.
17. Não transformar exemplo em regra oficial sem indicar status.
18. Não marcar nada como `canonico_oficial`.
