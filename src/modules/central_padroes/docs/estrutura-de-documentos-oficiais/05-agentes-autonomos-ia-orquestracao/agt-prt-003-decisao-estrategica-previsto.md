## Objetivo

Definir a sequência obrigatória para tomada de decisão estratégica no ecossistema GrupoB, delimitando quem recomenda e quem decide.

## Regra central

> **Nassar recomenda. Rodrigues decide.**

## Protocolo

### Fase 1 — Preparação (agente/Nassar)

1. Identificar que a decisão é **estratégica** (impacta mais de uma área, envolve recurso, muda direção).
2. Levantar dados, opções e riscos.
3. Estruturar recomendação clara: "Recomendo X porque Y."

### Fase 2 — Encaminhamento (agente)

4. Se o agente for operacional/tático: **subir para Nassar** (Diretor ou CEO).
5. Se o agente for Nassar: **preparar recomendação para Rodrigues**.

### Fase 3 — Decisão (Rodrigues)

6. Rodrigues ouve a recomendação.
7. Rodrigues decide: aprovar, ajustar, congelar ou recusar.
8. Decisão é **registrada** (ver `PROC-PAD-002` — Registro Estruturado de Decisão).

### Fase 4 — Execução

9. Decisão é comunicada aos envolvidos.
10. Execução é iniciada pelo responsável designado.

## O que é decisão estratégica

| É estratégico | Não é estratégico |
|---------------|-------------------|
| Criar nova venture | Escolher cor do botão |
| Definir metodologia oficial | Ajustar texto de e-mail |
| Alterar organograma | Priorizar tarefa do dia |
| Fechar unidade | Corrigir erro de digitação |
| Investir recurso significativo | Responder dúvida de cliente |

---

## Hierarquia de decisão

| Nível | Quem decide | Quem recomenda | Exemplo |
|-------|-------------|----------------|---------|
| 🔴 Chairman | Rodrigues | Nassar + Diretores | Nova venture, mudança estrutural |
| 🟠 CEO | Pedro Nassar | Diretores | Metodologia, alocação de recurso |
| 🟡 Diretor | Crispim, Álvaro, etc. | Agentes operacionais | Aplicação de metodologia |
| 🟢 Operacional | Agente autônomo | — | Execução dentro da alçada |

## Impasse

Se houver impasse entre níveis:

```
Operacional → Tático → Diretor → CEO (Nassar) → Chairman (Rodrigues)
```
