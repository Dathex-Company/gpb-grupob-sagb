## 1. Regra visual obrigatória

| Regra | Decisão |
|---|---|
| Fonte oficial | `Rubik` |
| Fallback | apenas técnico: `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `sans-serif` |
| Peso máximo | `700` |
| Pesos extremos | convertidos para `700` |
| Classes Tailwind extremas | `font-black` e equivalentes convertidos para `font-bold` |

## 2. Objetivo da segunda camada

Refinar a Central de Padrões para que as telas deixem de ser apenas funcionais e passem a ter consistência editorial, escaneabilidade, hierarquia visual e componentes reutilizáveis.

## 4. Refinamentos aplicados

| Área | Aplicação |
|---|---|
| Tipografia | Rubik e peso máximo 700 |
| Table/List | Wrapper e tabela padrão criados |
| FilterBar | Componente reutilizável com chips/limpar |
| MarkdownPreview | Tipografia editorial, headings, code inline, blockquote e bullets |
| Histórico | Painel composto com versões, contador, estado vazio/loading e ação restaurar |
| Eventos | Timeline visual com status, data, versão e transição |
| Modais | Modal crítico base criado |
| ActionBar | Barra visual reutilizável para ações primárias/secundárias |
| Dark mode | Usa tokens existentes e respeita contraste |
| Responsividade | Componentes em flex/grid responsivo e overflow seguro |
