# ADR-006 — Central de Padrões como embrião do Loze Docs

## 1. Título
Central de Padrões como embrião do Loze Docs.

## 2. Status
aprovado com ajustes

## 3. Contexto
A ET-03 organizou a estrutura documental canônica dentro de `src/modules/central_padroes/docs/` para servir de base do Loze Docs.

## 4. Decisão
Reconhecer formalmente a Central de Padrões do SagB como embrião do Loze Docs para padrões técnicos e institucionais.

## 5. Motivo
- preservar estrutura já em uso;
- evitar recriação desnecessária;
- centralizar governança documental.

## 6. Consequências
- padrões canônicos devem nascer/ser mantidos nesta central;
- execução e evidências permanecem nos módulos;
- nomenclatura final “Loze Docs” permanece em validação.

## 7. Impacto
alto (fonte canônica de documentação).
