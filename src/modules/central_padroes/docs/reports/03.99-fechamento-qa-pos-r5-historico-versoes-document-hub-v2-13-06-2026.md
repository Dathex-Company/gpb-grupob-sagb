## 🔗 Fluxo completo

```
Abrir doc → Editar → Salvar rascunho (cp_save_document_draft)
    → Publicar oficial (cp_publish_document) → versão N criada
    → Editar novamente → Publicar → versão N+1
    → Histórico: ver versões → Restaurar v1 (cp_restore_document_version)
    → Eventos: draft_saved, published, version_restored registrados
```
