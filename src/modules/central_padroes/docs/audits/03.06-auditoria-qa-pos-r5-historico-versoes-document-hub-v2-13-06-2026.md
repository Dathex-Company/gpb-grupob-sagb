## 2. Salvar rascunho

- **Código:** [`DocumentoEditorPage.saveDraft()`](../pages/DocumentoEditorPage.tsx) chama [`centralPadroesCrudService.saveDraft()`](../services/centralPadroesCrudService.ts) → RPC `cp_save_document_draft`
- **RPC:** UPSERT em `central_padroes_document_drafts` + atualiza `official_status` se não for `oficial_ativo` + insere evento `draft_saved`
- **UI:** Toast "💾 Rascunho salvo com sucesso."

## 3. Publicar oficial

- **Código:** [`DocumentoEditorPage.publishOfficial()`](../pages/DocumentoEditorPage.tsx) chama [`centralPadroesCrudService.publishDocument()`](../services/centralPadroesCrudService.ts) → RPC `cp_publish_document`
- **RPC:** Insere versão + atualiza documento + limpa rascunho + insere evento `published`
- **UI:** Toast "✅ Documento publicado como oficial ativo (versão N)." + confirmação dupla para re-publicação

## 4. Versões listadas

- **Código:** `listVersions` no CRUD → tabela `central_padroes_document_versions`
- **UI:** Painel "Histórico de versões" no editor — mostra versão, título, data, status oficial, botão Restaurar

## 5. Restauração validada

- **Código:** [`DocumentoEditorPage.restoreVersion()`](../pages/DocumentoEditorPage.tsx) → RPC `cp_restore_document_version`
- **RPC:** Busca versão alvo, restaura documento, limpa rascunho, insere evento `version_restored`
- **UI:** Dupla confirmação + reload do documento após restauração

## 6. Eventos editoriais

- **Código:** `listEvents` no CRUD → tabela `central_padroes_document_events`
- **UI:** Painel "Eventos editoriais" no editor — mostra tipo, versão, status anterior/novo, data

## 7. publishedAt/publishedBy

- **UI:** [`DocumentoDetalhePage`](../pages/DocumentoDetalhePage.tsx) — MetaCards "Publicado em" e "Publicado por"
- **Formato:** `new Date(publishedAt).toLocaleString('pt-BR')` ou "Ainda não publicado"
