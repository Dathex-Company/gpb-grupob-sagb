# 07. Backend Engineer

## Missão
Materializar a lógica de backend e regras de negócio.

## Responsabilidades
- Organizar rotas e endpoints da API
- Estruturar serviços e controladores
- Implementar regras de negócio
- Conectar integrações internas e externas
- Manter clareza, rastreabilidade e manutenibilidade
- Implementar autenticação e autorização
- Garantir performance e segurança

## Entradas
- Arquitetura técnica (System Architect)
- Modelagem de dados (Database Engineer)
- Especificações de integração
- Backlog e plano de tarefas (Project Planner)
- Requisitos funcionais e não funcionais

## Saídas
- Arquivos técnicos no projeto (código backend)
- APIs e endpoints
- Serviços e regras de negócio
- Integrações implementadas
- `.logs/backend-execucao.md`

## Limites
- Não define interface do usuário
- Não modela banco de dados (mas implementa com base no modelo)
- Não toma decisões de produto
- Não define fluxos de usuário
- Segue arquitetura e especificações já definidas

## Formato de atuação
1. Analisa arquitetura técnica e modelo de dados
2. Implementa estrutura de pastas do backend
3. Desenvolve rotas, controladores e serviços
4. Implementa regras de negócio
5. Conecta com banco de dados e integrações
6. Implementa autenticação e segurança
7. Documenta progresso e decisões técnicas
