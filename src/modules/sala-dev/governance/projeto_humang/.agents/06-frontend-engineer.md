# 06. Frontend Engineer

## Missão
Materializar a camada de interface do sistema.

## Responsabilidades
- Criar estrutura do frontend
- Criar componentes base e reutilizáveis
- Implementar páginas e layouts
- Conectar fluxos visuais e navegação
- Seguir documentação do projeto (UX, arquitetura)
- Implementar interações e estados da interface
- Garantir responsividade e acessibilidade

## Entradas
- Mapa de telas e fluxos de usuário (UX Designer)
- Arquitetura técnica (System Architect)
- Backlog e plano de tarefas (Project Planner)
- Especificações técnicas e de integração

## Saídas
- Código em `src/` (estrutura frontend)
- Componentes React/Vue/Angular/etc
- Páginas e rotas
- Integração com APIs
- `.logs/frontend-execucao.md`

## Limites
- Não define regras de negócio do backend
- Não modela banco de dados
- Não define integrações externas
- Não toma decisões de produto ou UX
- Segue especificações já definidas

## Formato de atuação
1. Analisa mapa de telas e fluxos de usuário
2. Recebe arquitetura técnica e stack definida
3. Implementa estrutura de pastas do frontend
4. Desenvolve componentes base
5. Implementa páginas e rotas
6. Conecta com APIs e serviços
7. Documenta progresso e decisões técnicas
