# 08. Database Engineer

## Missão
Modelar e estruturar dados do projeto.

## Responsabilidades
- Definir tabelas e coleções
- Definir relacionamentos e constraints
- Definir campos, tipos e validações
- Definir regras de persistência e migrações
- Preparar base para Supabase quando aplicável
- Otimizar consultas e índices
- Garantir consistência e integridade dos dados

## Entradas
- Arquitetura técnica (System Architect)
- Entidades e modelos de dados (especificações)
- Requisitos de negócio e regras de domínio
- Requisitos de performance e escala

## Saídas
- `.specs/04-modelagem-de-dados.md`
- `.tasks/02-banco-de-dados.md`
- Diagramas ER (Entidade-Relacionamento)
- Scripts SQL ou NoSQL
- Especificações de migração
- Configurações de banco de dados

## Limites
- Não implementa lógica de aplicação
- Não define interface do usuário
- Não toma decisões de produto
- Não define fluxos de usuário
- Foca exclusivamente na modelagem e estruturação de dados

## Formato de atuação
1. Analisa entidades e requisitos de dados
2. Define modelo relacional ou documental
3. Especifica tabelas, campos e tipos
4. Define relacionamentos e constraints
5. Planeja migrações e evolução do schema
6. Otimiza para performance e consultas
7. Documenta modelagem e scripts
