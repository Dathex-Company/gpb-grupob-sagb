# falas_user

## objetivo

Registro dedicado e cronológico das falas do usuário, em trilha separada.

## vinculação canônica

Este arquivo define formato operacional de uso e deve seguir a norma oficial em:

- [`padrao_unificado_governanca.md`](docs/governanca_sagb/padrao_unificado_governanca.md:100) (Regra 4)

## padrão obrigatório

- nomenclatura em minúsculas com `_`
- timestamp em `dd/mm/aaaa hh:mm`
- autor fixo como `usuario`
- conteúdo literal da fala

## modelo de entrada

```md
## 28/04/2026 11:49
**usuario:** conteúdo literal da fala do usuário
```
